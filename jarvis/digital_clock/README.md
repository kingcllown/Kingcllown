# Digital Clock - Timezone-Aware Time Display\n\nA professional, feature-rich digital clock module with full timezone support, designed for the Jarvis assistant framework.\n\n## Features\n\n✅ **Multi-Timezone Display**\n- Show time in multiple timezones simultaneously\n- 400+ IANA timezone identifiers\n- Support for custom nickname mappings (e.g., \"work\", \"home\")\n\n✅ **Multiple Display Formats**\n- 24-hour format (15:45:30)\n- 12-hour format with AM/PM (3:45:30 PM)\n- Short formats (15:45 / 3:45 PM)\n- Full date and time strings\n- ASCII art clock displays\n\n✅ **Timezone Management**\n- Pre-configured city mappings (Istanbul, London, Tokyo, Sydney, etc.)\n- Register custom nickname-to-timezone mappings\n- Search timezones by name\n- Get UTC offset information\n- View DST status\n\n✅ **Clock Functions**\n- Compare times across timezones\n- Calculate time remaining until next event\n- Track favorite timezones\n- Get continuous clock updates\n- Display noon/sunset times by timezone\n\n✅ **Jarvis Integration**\n- Ready-to-use `ClockSkill` for Jarvis assistant\n- Turkish language support in skill responses\n- Intent matching for voice commands\n\n## Installation\n\n```bash\n# Already included in main Jarvis requirements\npip install pytz\n```\n\n## Quick Start\n\n### Basic Usage\n\n```python\nfrom jarvis.digital_clock.world_clock import WorldClock\nfrom jarvis.digital_clock.clock_display import TimeFormat\n\n# Create world clock\nclock = WorldClock()\n\n# Display single timezone\ndisplay = clock.display.display_single_timezone(\"Istanbul\")\nprint(display)\n# Output: Istanbul           | 14:32:45 | UTC+03:00\n\n# Display multiple timezones\ntimezones = [\"Istanbul\", \"London\", \"New York\", \"Tokyo\"]\noutput = clock.display.display_multiple_timezones(timezones)\nprint(output)\n```\n\n### With Jarvis Assistant\n\n```python\nimport asyncio\nfrom jarvis.core.assistant import multi-timezone display\n- **Memory**: ~1MB for full IANA timezone database\n- **CPU**: Minimal when not updating; ~2% during 1s updates\n\n## Thread Safety\n\nThe module is **not thread-safe** by default. For multi-threaded use:\n\n```python\nimport asyncio\nfrom asyncio import Lock\n\nclass ThreadSafeWorldClock:\n    def __init__(self):\n        self.clock = WorldClock()\n        self._lock = Lock()\n\n    async def get_time_safely(self, timezone):\n        async with self._lock:\n            return self.clock.display.display_single_timezone(timezone)\n```\n\n## Contributing\n\nExtensions welcome!
